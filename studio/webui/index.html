📺 Connect YouTube how to get the file ▾

One-time Google setup (needed so the app can post to your channels):
  1. Go to console.cloud.google.com → create a project (any name).
  2. Enable the YouTube Data API v3 for it.
  3. APIs & Services → OAuth consent screen → External → fill the app name + your email → add yourself as a Test user.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID → type Desktop app → Create → Download JSON.
  5. Back here: click Upload Google credentials below, pick that JSON, then Connect each channel and sign in as that channel.
Note: brand-new API projects upload videos as Private until Google approves an audit — you flip them public in YouTube Studio (10s) meanwhile.
